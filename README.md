# Scrapbook Sanctuary

SCRAP

A cozy, playful notes, reading, and PDF annotation app

Build a polished, beautiful web application called Scrap.

Scrap is not meant to feel like a conventional productivity or notes application. It is a cozy personal creative space for reading, writing, studying, annotating PDFs, collecting ideas, doodling, and decorating pages with expressive hand-drawn stickers.

The initial version is primarily for personal use, but the architecture and visual system should be clean enough that the app could eventually become a shareable product.

The core philosophy is:

Clean functionality + tactile paper feeling + hand-drawn personality + cozy atmosphere.

The app should feel alive, warm, playful, slightly imperfect, and personal without becoming visually cluttered.

flowers, bows, hearts, stars, arrows, ribbons

book annotation aesthetics

handwritten-looking marks

scrapbook elements

cozy editorial composition

the Scrapy mascot





2. THE CORE FEEL

Scrap should feel like:

opening a favourite notebook

sitting down to read late at night

decorating the margins of a book

collecting tiny thoughts

highlighting a sentence that matters

throwing a sticker onto a page because it perfectly expresses your reaction

having a little companion living inside your workspace

It should NOT feel like:

Notion

Microsoft OneNote

Google Docs

a corporate PDF editor

a generic productivity dashboard

a sterile white canvas

an overly polished corporate SaaS product

Avoid excessive rounded-card UI, excessive gradients, generic SaaS illustrations, generic icon libraries, and overly childish rainbow colours.

The personality should come from paper, ink, doodles, stickers, movement, texture, and Scrapy.

3. COLOR DIRECTION

Primary visual identity:

Petal Forest + Espresso

Use a warm, restrained palette.

Core colours:

Petal pink

Dusty rose

Petal forest / muted botanical green

Sage

Warm paper cream

Soft parchment

Espresso brown

Occasional muted sky blue

Very occasional warm amber/gold for tiny accents

Espresso should function as the main ink/outline colour.

Paper and cream should provide the main writing surfaces.

Petal pink should appear in stickers, tape, blush, flowers, hearts, and playful accents.

Petal forest and sage should appear in botanical elements and subtle interface accents.

Do NOT make every component colourful.

The palette should feel curated and editorial.

4. BACKGROUND

The app must NOT use a literal desk background.

Do not create a wooden desk, desktop objects, bedroom scene, or physical desk environment.

Instead, create a beautiful atmospheric background that subtly breathes.

The background should feel alive but extremely calm.

Possible visual qualities:

soft layered gradients

muted botanical shapes

subtle blurred colour fields

very light paper grain

tiny floating particles

extremely slow ambient movement

soft light shifts

faint organic shapes around the edges

The movement must be subtle enough that it does not distract from reading or writing.

The user should mostly feel that the environment is alive rather than consciously noticing an animation.

The central workspace should remain highly readable.

organizing notes

Users should be able to:

unfinished ideas

STICKERS

The sticker library should feel like opening a personal sticker collection rather than opening a conventional icon picker.

SETTINGS

Simple settings for things such as:

appearance

background atmosphere

export/import options

6. SCRAPY

Scrapy is the small mascot and emotional companion of the application.

Scrapy is NOT just another sticker.

Scrapy is the little character who lives inside Scrap.

The character should retain these important visual characteristics:

irregular torn-paper/blob body

warm paper-colored body

expressive minimal face

espresso/dark hand-drawn outline

tiny blush

small piece of colored tape attached to the body

slightly imperfect silhouette

handmade paper/sticker feeling

Scrapy should remain visually simple.

The personality should come from posture, expression, tape movement, and context.

Create several states:

idle

happy

greeting

curious

sleepy

excited

thinking

tired

surprised

proud

emotional

celebrating

Scrapy can subtly react to the user's actions.

Examples:

When opening Notes:
Scrapy appears calm and welcoming.

When opening PDFs:
Scrapy appears ready to read.

When annotating:
Scrapy becomes curious or excited.

After prolonged reading:
Scrapy may become sleepy.

When creating an idea dump:
Scrapy can become energetic or thoughtful.

Late at night:
Scrapy can appear sleepy.

These reactions should be subtle and charming, never distracting.

7. SCRAPY ROOM COLORS

Scrapy's tape can visually identify the current space.

For example:

Notes / Journal:
dusty rose

PDFs:
soft sky blue

Idea Dump:
sage / petal forest

The tape colour becomes a small visual navigation cue throughout the application.

This system should feel natural, not like a rigid colour-coded productivity system.

8. NAVIGATION

Do not make the interface feel like a standard SaaS sidebar.

Navigation should still be extremely usable, but visually integrated into the Scrap world.

Possible structure:

A compact left-side navigation containing:

Scrap logo/name

Notes

PDFs

Idea Dump

Stickers

Settings

Use small expressive icons and subtle hand-drawn details.

The current section should have a tactile paper/tape-like active state.

Transitions between sections should feel soft and spatial.

Avoid harsh page reload-style transitions.

The environment should feel continuous.

9. STICKER SYSTEM

The sticker system is one of the most important parts of Scrap.

The stickers should feel inspired by real book marginalia and personal scrapbook pages.

They should NOT look like polished commercial emoji packs.

Use:

irregular hand-drawn outlines

espresso ink

paper-like fills

selective pastel accents

slightly imperfect proportions

subtle paper texture

tiny shadows where appropriate

varied rotation

tactile placement

Stickers should have enough imperfection to feel handmade.

11. HIGHLIGHTER

The highlighter is a particularly important interaction.

It must have self-straightening behavior.

When the user draws a highlight across text, the stroke should automatically straighten into a clean horizontal highlight while retaining a slightly organic, hand-drawn texture.

It should NOT look like a perfectly sterile rectangle.

The result should feel like:

a real highlighter stroke that naturally became neat.

The user should be able to drag approximately across a line and let Scrap correct the geometry.

Support several highlighter colours from the Scrap palette.

Suggested:

dusty pink

muted lavender

sage

soft sky

warm cream/gold

The highlighter should remain translucent enough that text underneath stays readable.

The toolbar should feel tactile and playful.

13. INTERACTION DESIGN

Objects should feel physical.

When placing a sticker:

it appears with a tiny scale-in animation

it can have a tiny random rotation

it should feel like it was placed onto paper

dragging should feel smooth

selected objects should have subtle controls

resizing should be easy

deleting should be simple

Do not overanimate everything.

The goal is tactile, not flashy.

14. PAPER & TEXTURE

Use subtle texture throughout the application.

Paper surfaces can have:

very subtle grain

tiny imperfections

warm off-white colouring

faint paper fibers

slightly irregular edges where appropriate

Avoid making the entire interface look like an old parchment fantasy game.

The texture should be modern and sophisticated.

15. TYPOGRAPHY

Use a combination of:

clean modern sans-serif for functional UI

handwritten/display font for selected labels and playful moments

monospaced or compact type sparingly for tiny metadata if useful

Handwritten typography should never reduce usability.

All important controls and functional text must remain highly readable.

16. NOTES EXPERIENCE

The Notes screen should feel like opening a beautiful notebook.

Users should see their pages as tactile paper cards/pages rather than generic rectangular dashboard cards.

Include:

page title

last edited time

preview

new page

search

simple organization

Creating a note should immediately feel inviting.

The user should be able to start writing without navigating through multiple setup screens.

17. PDF EXPERIENCE

PDFs are one of the core features, not an afterthought.

The reading interface should prioritize the document.

Keep the surrounding UI quiet.

Allow users to:

upload

browse pages

zoom

highlight

annotate

place stickers

draw

undo/redo

navigate pages

Annotations should stay attached to their correct PDF page and position.

The visual language should make PDF annotation feel closer to annotating a physical book than editing a corporate document.

18. IDEA DUMP

Idea Dump should be the messiest and most playful area.

Allow free placement of:

text

stickers

scraps

doodles

arrows

images if supported

handwritten notes

The canvas should not force everything into a strict grid.

It should encourage creative mess while remaining usable.

19. MICRO-ANIMATIONS

Use small moments of life:

Scrapy blinking

tape gently moving

stickers landing with a tiny bounce

pages sliding softly

background particles drifting

subtle ambient background movement

hover states that feel tactile

small paper movements

Avoid:

excessive bouncing

loud transitions

fast animations

distracting parallax

anything that interferes with reading

Provide an option to reduce or disable ambient animation.

20. RESPONSIVENESS

The app should work beautifully on:

desktop

laptop

tablet

Prioritize desktop and tablet because PDF annotation benefits from a larger canvas.

The UI should remain clean at different screen sizes.

21. OVERALL DESIGN RULE

Every element should answer this question:

“Would this feel at home in a beautifully annotated book?”

If yes, keep it.

If it feels like generic SaaS UI, redesign it.

The app should feel like:

a cozy digital scrapbook + notebook + reading corner + annotation studio.

Not a productivity dashboard.

Not a generic notes app.

Not a generic PDF editor.

It should feel unmistakably like Scrap.

22. MVP PRIORITY

Build the first version around the strongest core experience:

Beautiful Scrap atmosphere

Notes

PDF viewing and annotation

Self-straightening highlighter

Pen / pencil / underline / arrows

Sticker placement

Sticker library

Scrapy mascot and reactions

Idea Dump

Autosave / persistence

Undo/redo

Clean responsive UI

Do not sacrifice the core experience by adding dozens of unnecessary features.

The first version should feel small, polished, charming, and deeply intentional.

The guiding phrase for the product is:

“A cozy little place to read, write, doodle, and remember.”

And the emotional goal is:

When I open Scrap, I should actually want to stay there.
